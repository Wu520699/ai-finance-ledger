# AI 票据智能台账（业财融合实践 v0.1）

面向小微餐饮门店的「票据识别 → 自动入账 → 经营复盘」小工具。
职业方向：智能财务 / 业财融合。

## 一句话说明

把店里的收款截图、进货单、水电缴费单丢进来，AI 认字段，脚本按会计科目自动入账，
生成台账 + 成本结构 + 毛利 + 经营小结，让财务数据直接回到经营决策上。

## 流程

1. 票据 / 收款截图 → AI 多模态识别（日期、摘要、金额、收付、支付方式）
2. 结构化流水写入 `data/raw_tickets.csv`
3. `src/build_ledger.py` 按规则映射会计科目（食材、包装、水电、房租、人工、平台佣金…）
4. 输出 `out/台账.xlsx`（明细台账 / 科目汇总 / 日汇总 / 经营小结）与 `out/经营小结.txt`

## 目录

```
ai-finance-ledger/
├── data/raw_tickets.csv     # AI 识别后的结构化流水
├── src/build_ledger.py      # 科目映射 + 汇总 + 出表
└── out/                     # 台账.xlsx、经营小结.txt
```

## 用法

```bash
python3 src/build_ledger.py
```

## 已实现（v0.1）

- 收支分流、9 类费用科目 + 其他支出的关键词映射
- 明细台账、科目汇总（含占比）、日汇总（含当日净额）
- 毛利率、食材成本占比、成本结构、经营提示自动成文
